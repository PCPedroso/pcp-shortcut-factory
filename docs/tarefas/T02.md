# T02: Utilitários de tempo hh:mm:ss.cc

**Objetivo:** converter e conferir tempos no formato do projeto (`hh:mm:ss.cc`).

**Arquivos permitidos:** criar `src/cortesia/tempo.py` e `tests/test_tempo.py`.

**Proibido tocar:** `schemas/`, `tests/fixtures/`, `prompts/`, `requirements.txt`.

**Entradas e saídas:**
- `segundos_para_tempo(segundos: float) -> str`: arredonde para centésimos com aritmética
  inteira (`round(x * 100)`), sempre com horas e 2 casas. `59.999` vira `"00:01:00.00"`.
- `tempo_para_segundos(texto: str) -> float`: aceita só o formato exato; senão `ValueError`.
- `duracao_confere(inicio: str, fim: str, duracao_segundos: float, duracao_formatada: str) -> bool`:
  verdadeiro se `fim - inicio` bate com os dois valores (tolerância de 0,01 s).

**Critérios de aceite:**
1. Exemplos: `0.08 -> "00:00:00.08"`, `109.40 -> "00:01:49.40"`, `1424.88 -> "00:23:44.88"`,
   `3600 -> "01:00:00.00"`.
2. Ida e volta: `tempo_para_segundos(segundos_para_tempo(x))` igual a `x` (2 casas) para valores variados.
3. Negativos e formatos inválidos (`"1:02"`, `"00:01:49"`, `"00:60:00.00"`) levantam `ValueError`.
4. Todos os cortes do gabarito `gabarito_textos_c1_c7_c8.json` passam em `duracao_confere`.

**Fora de escopo:** qualquer leitura de transcrição.

**Definição de pronto:** `ruff check .` e `pytest -q` sem erros; backlog atualizado;
relatório entregue.
