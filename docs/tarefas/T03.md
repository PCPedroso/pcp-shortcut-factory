# T03: Leitor de transcrição e tempo efetivo das falas

**Objetivo:** carregar a transcrição em JSON e calcular o fim efetivo de cada fala.

**Contexto:** em legendas automáticas os segmentos se sobrepõem. O `start` de cada linha
aproxima o momento da primeira palavra; o fim efetivo de uma fala é o `start` da linha seguinte
(para a última, o próprio `end`). Não use o `end` do segmento como fim da fala.

**Arquivos permitidos:** criar `src/cortesia/transcricao.py` e `tests/test_transcricao.py`.

**Proibido tocar:** `schemas/`, `tests/fixtures/`, `prompts/`, `requirements.txt`.

**Entradas e saídas:**
- `@dataclass(frozen=True) Segmento(inicio: float, fim: float, texto: str, fim_efetivo: float)`.
- `@dataclass(frozen=True) Transcricao(segmentos: tuple[Segmento, ...], idioma: str, duracao_aproximada: float)`.
- `carregar_transcricao(caminho: Path) -> Transcricao`: lê JSON com a chave `transcript_segments`
  (itens com `start`, `end`, `text`). `idioma` vem de `selected_language_code`.
- Levante `TranscricaoInvalida` (exceção própria) se `error` estiver preenchido, se não houver
  segmentos ou se faltar campo.
- `duracao_aproximada` = `end` do último segmento.

**Critérios de aceite (com `tests/fixtures/transcript_tuVNNEO-NKc_pt.json`):**
1. 685 segmentos; primeiro `inicio` = 0.08; `duracao_aproximada` = 1424.88.
2. `fim_efetivo` de cada segmento (exceto o último) = `inicio` do seguinte; do último = seu `fim`.
3. Os campos `source` e `selected_language` NÃO são tratados como canal do vídeo.
4. JSON com `error` preenchido, ou lista vazia, levanta `TranscricaoInvalida`.
5. Textos preservam acentos (UTF-8).

**Fora de escopo:** dividir em frases, detectar autopromoção, segmentar por assunto (T05, T06).

**Definição de pronto:** `ruff check .` e `pytest -q` sem erros; backlog atualizado;
relatório entregue.
